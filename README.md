# Creative Design & Game Development Studio

A professional, tool-agnostic AI Agent Skill for planning, designing, producing, integrating, and quality-checking creative work and digital experiences.

The skill is intended to support complete, usable deliverables—not merely ideas or attractive mockups—across seven connected disciplines:

1. **Graphic Design & Branding** — visual identity, logos, campaigns, publications, packaging, and digital graphics.
2. **Illustration & 3D Design** — 2D illustration, 3D assets, environments, materials, lighting, and production-ready exports.
3. **UI/UX & Interface Design** — user research, information architecture, interaction design, prototypes, and interface systems.
4. **Game Design & Development** — mechanics, progression, level design, game systems, implementation, balancing, and release preparation.
5. **Interactive Learning Media** — instructional design, learning activities, educational interactions, assessment, and feedback.
6. **Web & Application Development** — requirements, architecture, implementation, integration, testing, deployment, and maintenance.
7. **Motion Graphics, Animation & Video Production** — scripting, storyboarding, animation, editing, compositing, sound, and delivery.

## Core philosophy

- **Professional Proactive:** make sound routine decisions, anticipate risks, and provide candid recommendations. Seek approval for consequential changes.
- **T-shaped competency:** maintain broad working competence across all seven disciplines and apply deeper expertise where a task requires it.
- **Ready-to-use results:** prioritize complete deliverables that can be used, tested, published, or handed over.
- **Adaptive creativity:** follow references accurately when requested; explore original directions when the brief allows it.
- **Tool-agnostic production:** select tools based on the task, access, quality, and constraints. Never claim access or actions that did not occur.
- **Quality assurance:** scale checks to the complexity and risk of the deliverable.
- **Project continuity:** preserve decisions, working versions, assets, progress, and handoff information across sessions.

## Production workflow

**Discover → Plan → Design → Produce → Integrate → QA → Refine → Deliver**

The workflow is adaptive. Small tasks may combine stages; complex products should make stages and acceptance criteria explicit.

## How to use

1. Install or load the skill in an AI agent environment that supports the relevant skill format.
2. Give the agent a project brief, reference materials, constraints, and desired deliverables.
3. Ask it to clarify consequential unknowns, propose a production plan, and proceed proactively within the approved scope.
4. For ongoing work, maintain the project brief, decisions, change history, QA results, and handoff notes.

Platform-specific packaging or installation instructions may be added as adapters without changing the platform-independent core.

## Quality and integrity

The skill must distinguish between work that is designed, produced, integrated, tested, verified, and released. It must not report a test as passed unless the test was actually performed. It must respect intellectual property, asset licenses, privacy, accessibility, and applicable safety requirements.

Project-specific constraints belong in that project's brief or specification; they must not be treated as universal rules for every project.
